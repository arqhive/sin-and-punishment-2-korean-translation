완성판입니다. 대사를 원문과 다시 대조하고, 글씨를 원본 게임과 어울리게 다듬었습니다.

**원본 일본판 이미지에 적용하는 전체 패치입니다.** 이전 버전이나 하스피님 한글판을 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

### 대사와 문장

- 컷신 자막 36줄을 원문과 다시 대조해 다듬었습니다. 빠진 말을 채우고, 원문에 없는 뜻이 덧붙은 대사를 원문대로 고쳤습니다.
- 녀석과 놈을 원문에 맞게 구분했습니다.
- 공중 액션 튜토리얼의 「컨트롤 스틱을 상으로 입력하면」을 「위쪽으로 입력하면」으로 고쳤습니다.

### 글씨

- 메뉴·설명문 글꼴을 나눔고딕으로 바꾸고, 들쭉날쭉하던 글자 간격을 고르게 맞췄습니다.
- 컷신 자막 글꼴을 둘기마요로 바꾸고 원본 자막처럼 살짝 기울였습니다.
- 자막 글씨 크기를 모두 같게 맞췄습니다. 문장이 긴 자막만 작게 보이던 문제가 없어졌습니다.
- 자막 외곽선과 그림자를 원본 자막과 같은 세기로 맞췄습니다.
- 자막에서 문장과 문장 사이가 지나치게 넓던 간격을 줄였습니다.
- 스테이지 선택 화면의 스테이지 이름 글꼴을 본명조로 바꿨습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `R2VJ_KPatch_v1.2f.zip` | 원본 일본판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 지원 형식

| 원본 | 결과 |
|---|---|
| ISO (정본 덤프, WBFS에서 변환한 ISO 등) | ISO |
| WBFS | WBFS |
| CISO, WIA, WDF | ISO |
| RVZ · NKit | 지원 안 함. ISO로 변환·복원한 뒤 적용 |

덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.

## 적용 방법

1. zip을 풀고 원본 이미지(ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다. 원본을 같은 폴더에 넣고 더블클릭해도 됩니다.
2. `완료`가 나올 때까지 기다립니다(보통 1분 안팎).
3. 원본과 같은 폴더에 결과 파일이 생깁니다.
   - ISO 원본 → `Tsumi to Batsu - Sora no Koukeisha (Korean) [R2VJ01].iso`
   - WBFS 원본 → `Tsumi to Batsu - Sora no Koukeisha (Korean) [R2VJ01].wbfs`

결과 형식을 바꾸려면 패처 폴더의 PowerShell에서 `powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"`처럼 결과 확장자를 지정합니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 오류 메시지와 해결 방법은 동봉한 `README_한국어.txt`를 참고하세요.
