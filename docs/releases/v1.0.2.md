배포 방식만 바꾼 판입니다. 번역·폰트·자막·그래픽은 v1.0.1과 같습니다.

**원본 일본판 이미지에 적용하는 전체 패치입니다.** v1.0.1이나 하스피님 한글판을 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

- ISO 통째 xdelta 대신 파일 단위 패처로 배포합니다. 덤프·변환 방법에 따라 MD5가 다른 이미지(WBFS, WBFS에서 변환한 ISO 등)에도 적용됩니다.
- 패치 크기가 34MB에서 약 6MB로 줄었습니다. 패처 도구(wit, xdelta3)가 들어 있어 따로 설치할 것이 없습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `SinAndPunishment2_KO_v1.0.2.zip` | 원본 일본판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 지원 형식

| 원본 | 결과 |
|---|---|
| ISO (정본 덤프, WBFS에서 변환한 ISO 등) | ISO |
| WBFS | WBFS |
| CISO, WIA, WDF | ISO |
| RVZ · NKit | 지원 안 함. ISO로 변환·복원한 뒤 적용 |

덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.

## 적용 방법

1. zip을 풀고 원본 이미지(ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다. 원본을 같은 폴더에 넣고 더블클릭해도 됩니다.
2. `완료`가 나올 때까지 기다립니다(보통 1분 안팎).
3. 원본과 같은 폴더에 결과 파일이 생깁니다.
   - ISO 원본 → `Tsumi to Batsu - Sora no Koukeisha (Korean) [R2VJ01].iso`
   - WBFS 원본 → `Tsumi to Batsu - Sora no Koukeisha (Korean) [R2VJ01].wbfs`

결과 형식을 바꾸려면 패처 폴더의 PowerShell에서 `powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"`처럼 결과 확장자를 지정합니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 오류 메시지와 해결 방법은 동봉한 `README_한국어.txt`를 참고하세요.
