타이틀 로고와 Wii 메뉴 배너·아이콘을 새 디자인으로 바꾼 업데이트입니다. 게임 텍스트, 자막, 폰트, 나머지 그래픽은 v1.0과 같습니다.

**원본 일본판 ISO에 적용하는 전체 패치입니다.** v1.0 한글판 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 타이틀 로고 「죄와 벌」과 부제 「우주의 후계자」를 원본처럼 붓글씨 느낌이 나는 새 디자인으로 바꿨습니다.
- Wii 메뉴 배너의 로고·부제와 그림자판, 아이콘 로고도 같은 디자인으로 맞췄습니다.

## 적용 방법

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Tsumi to Batsu - Sora no Koukeisha (Japan).iso" SinAndPunishment2_KO_v1.0.1.xdelta "Tsumi to Batsu - Sora no Koukeisha (Korean).iso"
   ```

2. 결과 파일의 확인값을 아래 표와 비교합니다.
