한식구 카페 하스피님의 한글 패치를 활용해 번역과 폰트, 자막을 다시 만들고 그래픽 한글화 범위를 넓힌 첫 버전입니다.

**원본 일본판 ISO에 적용하는 전체 패치입니다.** 하스피님 한글판 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 메뉴, 옵션, 튜토리얼, 경고·오류 메시지 등 게임 텍스트 305개를 일본어 원문과 대조해 다시 번역했습니다.
- 기존 패치에서 빠져 있던 문장(이름 입력, Y축 반전, 방향 입력 안내 등)을 번역했습니다.
- 하단 도움말 줄에서 줄바꿈 자리의 띄어쓰기가 붙어 나오던 문제를 고쳤습니다.
- 컷신 자막 270줄을 다시 번역하고 자막 이미지 39장을 새로 그렸습니다. 좁은 칸에서 잘리거나 비어 나오던 자막 5줄을 고쳤습니다.
- 한글 폰트를 Pretendard로 바꾸고 원본 글꼴처럼 외곽선과 그림자를 넣었습니다.
- 스테이지 이름, Wii 스트랩·재퍼 주의 화면, 엔딩 스태프롤, 타이틀 로고, Wii 메뉴 배너·아이콘을 한글화했습니다.

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Tsumi to Batsu - Sora no Koukeisha (Japan).iso" SinAndPunishment2_KO_v1.0.xdelta "Tsumi to Batsu - Sora no Koukeisha (Korean).iso"
   ```
