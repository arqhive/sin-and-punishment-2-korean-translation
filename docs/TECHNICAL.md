# 기술 문서

일본판 `R2VJ01` 기준입니다. 한글화로 바뀌는 파일은 DATA 파티션의 네 개뿐입니다.

| 파일 | 내용 | 도구 |
|---|---|---|
| `sys/main.dol` | 게임 텍스트 305개 (SJIS, NUL 종결) | `textenc.py`, `build.py` |
| `files/MsgFont.brfnt` | 게임 텍스트용 폰트 (RFNT) | `fontgen.py` |
| `files/texture.arc` | 컷신 자막 이미지와 그림 글씨 | `subgen.py`, `gfx_*.py` |
| `files/opening.bnr` | Wii 메뉴 배너·아이콘 | `banner.py` |

## 게임 텍스트 (main.dol)

- 문자열은 `main.dol`의 데이터 섹션(0x2C6D00에서 0x319300까지)에 SJIS로 들어 있고, 코드가 주소로 직접 가리킵니다. 포인터를 옮길 수 없으므로 원래 자리(슬롯)에 덮어쓰고 남는 부분은 0으로 채웁니다.
- 제어 바이트: `01 FF FF 01`/`01 FF FF FF`는 제목 강조의 시작과 끝, `01 FF 01 FF`/`01 FF FF FF`는 버튼 이름 강조입니다. `%s`에는 버튼 이름이 들어가고, 짧게 누르는 조작이면 게임이 `%s%s`로 "短押し" 문자열(0x319280)을 이어 붙입니다.
- 하단 도움말 줄은 설명문의 줄바꿈을 공백 없이 한 줄로 이어 붙여 보여 줍니다. `textenc.py`는 첫 줄바꿈(제목과 설명 사이) 뒤의 줄바꿈 앞에 공백을 넣습니다.
- 한글 음절은 SJIS 사용자 정의 영역 0xF040부터 차례로 코드를 붙입니다. 게임의 2바이트 판별 범위(리드 바이트 0x81에서 0x9F, 0xE0에서 0xFC)에 들어가면서 원래 가나·한자 코드와 겹치지 않습니다.
- 빌드는 가나가 두 글자 이상 든 문자열이 번역 목록에 모두 있는지 검사합니다.

## 폰트 (MsgFont.brfnt)

- RFNT, 셀 26×30, IA4, 시트 20장×37칸 = 740칸입니다. CMAP 블록 데이터는 블록 시작 +0x14부터입니다.
- 파일 뒤에 여유 공간이 없어 시트를 늘릴 수 없습니다. ASCII·기호·전각 영숫자는 그대로 두고, 가나·한자 칸에 한글을 그립니다.
- 원본 폰트에는 반각 `# $ & , : = ? @ [ ] ^` 글리프가 없어서 인코더가 전각으로 바꿉니다.

## 컷신 자막과 그림 글씨 (texture.arc)

- `texture.arc`는 자체 NARC 형식입니다. 헤더는 `NARC`, 개수, 이름표 크기, 데이터 시작이고, 항목은 16바이트 `{플래그, 이름 오프셋, 데이터 오프셋, 크기}`입니다. 항목마다 BRRES TEX0 텍스처가 하나씩 들어 있습니다.
- 자막은 `TX{스테이지}_{장면}_{번호}` 텍스처(IA4) 39장입니다. 줄마다의 위치는 스테이지 arc(`s0*.arc`) 안 SPRX 블록의 float 사각형(좌표와 UV)에 있습니다. `subgen.py`는 SPRX 사각형마다 한 줄씩 그리고, 넘치면 글자를 줄입니다.
- 그림 글씨: 스테이지 이름 `M_BG02/03`(RGBA8), 주의 화면 `STRAPA_JP`·`STRAPB_JP`(RGB565), `ZAPPER_JP`(CMPR, 바뀐 4×4 블록만 다시 압축), 스태프롤 `M_STAF01`에서 `05`까지(IA4), 타이틀 로고 `TITLE_LOGO`(RGBA8)입니다.

## 배너 (opening.bnr)

- IMET 헤더 뒤에 U8 아카이브가 있고, 그 안의 `banner.bin`·`icon.bin`은 IMD5 + LZ77(0x10)로 싼 U8입니다.
- 로고 TPL 다섯 장(C8/RGB5A3 팔레트, IA8)을 새 타이틀 로고를 줄여 교체합니다. 파일이 원래 크기보다 커지면 안 되므로 LZ77은 최적 분할로 압축합니다.

## 디스크 이미지 재구성

wit로 이미지를 새로 만들면 파일 배치가 바뀌어 xdelta가 수백 MB가 됩니다. `inplace.py`는 원본 배치를 그대로 씁니다.

1. wit로 원본을 배치 그대로 복호화합니다.
2. 바뀐 파일 네 개를 원래 자리에 덮어씁니다.
3. 바뀐 2MB 그룹의 H0·H1·H2 해시를 직접 계산해 넣습니다.
4. wit로 다시 암호화합니다(`--enc ENCRYPT`는 해시를 다시 계산하지 않음).
5. 원본 ISO 사본에 바뀐 그룹만 옮기고, H3 표와 TMD의 콘텐츠 해시를 갱신한 뒤 TMD에 가짜 서명을 합니다.
